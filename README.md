## 📋 The Docket

```diff
+ Building agent-native operating systems, one append-only log at a time
+ Local-first · human-gated · capability-secured — humans hold the keys
+ Python, Rust, TypeScript — from silicon homelab to cloud orchestration
! Currently running a one-person ecosystem: Connect / Decima / Seam
- Not here for hype — here for working systems
```

I'm **Matthew J.** (`Judge-M`). Over the last year I've gone from my first AI chat to
designing and shipping a full stack of agent infrastructure — and I document the climb
so others can make it too.

**What I work on:**

- 🧠 **Agent memory** — trusted, human-gated ledgers with provenance, contradictions & supersession
- 🛠️ **Tool governance** — registries, brokers and security boundaries for AI tools
- ⚙️ **Compute orchestration** — local + cloud workload placement through pluggable adapters
- 🏛️ **Control planes** — where agent tasks, reviews, audits and handoffs get judged
